Comment ce site a été fait

Les décisions viennent d’Alexis ; l’IA Claude (Anthropic) a accéléré la production. Voici qui a fait quoi.

Ce qu’Alexis a fait

Il a fixé la direction : garder son univers de scènes en 3D, le rendre professionnel et en faire un CV interactif. Il a choisi le positionnement et l’accroche, l’univers unique des coulisses, les quatre portes (Web, Communication, Graphisme, Coordination) et les projets à montrer. Il a fourni les faits (rôles, dates, outils, résultats), les images et le logo du festival, et il a validé chaque grande étape : charte, maquettes, textes.

Le portfolio part de la première version qu’il avait conçue et intégrée lui-même : l’idée des scènes, la caméra en CSS 3D, le mur de production.

Ce que l’IA a accéléré

Claude, l’assistant d’Anthropic, a travaillé sous la direction d’Alexis, une tâche à la fois : l’audit de la première version, la charte, les maquettes, la reprise du code (SCSS, JavaScript, PHP), les pages des projets, le CV express et le CV en PDF, puis les tests (ordinateur, téléphone, « moins d’animations »). Les textes viennent des faits donnés par Alexis ; ce qui manquait lui a été demandé plutôt qu’inventé.

Outils

  • HTML
  • SCSS
  • JavaScript
  • GSAP
  • PHP
  • Figma
  • GitHub
  • Claude

Pas de bibliothèque d’interface : du HTML sémantique, du SCSS construit sur des jetons de couleur, du JavaScript sans framework. Les polices et GSAP sont hébergées avec le site, et le code est public sur GitHub.
